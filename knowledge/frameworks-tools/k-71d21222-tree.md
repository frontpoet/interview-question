# Tree Shaking 与模块副作用

## 核心概念

Tree Shaking 删除可证明未被使用且可安全移除的代码，依赖模块静态分析和副作用判断。

## 原理与机制

构建器从入口分析 ESM 导入导出，标记未使用导出，再由优化过程移除代码。sideEffects 声明辅助判断整个模块能否被跳过；usedExports 关注导出是否使用。

## 适用边界与易错点

具名 import 不保证只留下一个函数，其依赖和有副作用的初始化仍可能保留。CommonJS、动态访问和不准确的 sideEffects 配置影响结果。CSS 导入常有副作用；错误声明可误删样式。
