# 渐进加载与布局稳定性

## 核心概念

渐进加载按区域展示已就绪内容。骨架屏是对未知内容的布局占位，用于降低等待感和布局跳动。

## 原理与机制

骨架与真实组件共用尺寸、间距和响应式规则；图片预留 width/height 或 aspect-ratio。先展示可用文字，再替换就绪的图片或异步模块，而非等待整个页面 load。

## 适用边界与易错点

首屏骨架应存在于初始 HTML/SSR 输出并配套关键 CSS；只在应用 JS 执行后创建的骨架不能覆盖 JS 加载前的空白。未知数据无法保证精确预测，需合理占位并提供失败、空态和重试状态。
