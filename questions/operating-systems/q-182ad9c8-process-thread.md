# 进程和线程有什么区别？

## 题目

比较资源、隔离、通信、调度和故障影响。

## 简要回答

| 维度 | 进程 | 同进程线程 |
| --- | --- | --- |
| 地址空间 | 通常独立 | 共享 |
| 执行状态 | 含一个或多个线程 | 各有栈和寄存器等状态 |
| 数据交换 | 通常需 IPC | 可访问共享数据，需同步 |
| 隔离 | 较强 | 一个线程破坏内存可能影响全进程 |
| 切换成本 | 可能涉及地址空间变化 | 通常少一些资源切换，但不保证总更快 |

“进程是资源单位、线程是调度单位”适合作为概括；实际内核调度模型需注明系统。并发不等于并行，是否并行取决于核心数和运行时等条件。
