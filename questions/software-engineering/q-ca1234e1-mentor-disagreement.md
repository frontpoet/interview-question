# 与 mentor 有技术分歧时，如何处理？

## 题目

和 mentor 有过意见分歧吗？如何沟通、做出决定并落实？

## 简要回答

先举真实分歧，说明双方分别担心什么；对齐目标和约束，把方案转为可比较的指标或风险，必要时做小型实验，再由明确的负责人决策。决定后配合落地，并约定验证和复盘条件。

## 回答组织示例

“在【真实任务】中，我倾向【方案 A】，mentor 考虑【风险】倾向【方案 B】。我们先确认【共同目标】，我补充了【原型/数据/文档】，比较【性能、成本、交付周期】后选择【方案或折中】。我负责【后续行动】，结果是【真实反馈】，这次让我调整了【原先假设】。”

## 分析与边界

若没有明显冲突，可以如实讲方案讨论，不要编造对抗。证据证明自己判断有误时应直接承认；无法及时达成一致时按团队决策机制升级，同时说明影响、备选方案与期限。涉及重大安全或合规问题时应走相应评审渠道，不能只因对方资历高而忽略。
